# Aqua Zielony Zakątek

## O projekcie
Aqua Zielony Zakątek to responsywna, wielostronicowa aplikacja internetowa stworzona z myślą o początkujących i zaawansowanych pasjonatach akwarystyki. Serwis służy jako interaktywny poradnik – przeprowadza przez proces zakładania pierwszego zbiornika krok po kroku, pomaga w doborze odpowiednich gatunków ryb i roślin oraz oferuje kalkulator litrażu z możliwością zapisywania planowanej obsady.

## Wykorzystane technologie
* **HTML5** (semantyczna struktura strony, geolokalizacja)
* **CSS3** (własne style, zmienne globalne, animacje)
* **JavaScript** (programowanie obiektowe, LocalStorage, DOM API)
* **Bootstrap 5** (system siatki, responsywność RWD, komponenty karuzeli i kart)
* **jQuery** (obsługa interakcji interfejsu)
